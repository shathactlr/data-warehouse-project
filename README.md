
# End-to-End SQL Data Warehouse Project

## Project Overview
This project involved building a Data Warehouse using **SQL Server Management Studio (SSMS)** to transform raw business data into actionable insights. A multi-layer architecture was implemented to ensure a scalable and reliable data pipeline.

## Key Features
* **Data Architecture:** Developed a three-tier architecture (**Bronze, Silver, and Gold Layers**) for structured data management.
* **Automated ETL:** Built robust ETL pipelines to extract data from CRM and ERP sources, applying complex transformations and data cleansing.
* **Data Quality:** Implemented deduplication logic, standardized categorical values, and ensured schema enforcement for data integrity.
* **Data Modeling:** Designed a **Star Schema** in the Gold Layer, optimizing the environment for business intelligence and analytical reporting.

## Tech Stack
* **Database Management:** SQL Server Management Studio (SSMS).
* **Core Logic:** SQL (Stored Procedures, Window Functions, Data Transformation).
* **Framework:** Medallion Architecture & Star Schema Modeling.
